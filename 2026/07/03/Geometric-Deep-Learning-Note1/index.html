几何深度学习蓝图

关键词：学习、维度灾难、对称性、形变稳定性

1. 引言（Introduction）

1.1 深度学习的两个核心原则

  • 表示学习 / 特征学习（Feature Learning）：自适应的、通常是层次化的特征，为每个任务捕捉合适的规律性
  • 局部梯度下降（Backpropagation）：通过反向传播实现

1.2 高维学习的困境

  • 在通用高维函数空间中学习是”被诅咒的估计问题”（维数灾难）
  • 但现实任务并非通用——底层物理世界的低维性与结构赋予了数据本质的规律性
  • 本文目标：通过统一的几何原理揭示这些规律性

1.3 来自 Erlangen 纲领的启发

  • Felix Klein (1872)：几何学是不变量的研究——在特定变换群下保持不变的性质
  • 十九世纪末的几何学流派纷争 → Klein 用群论统一
  • 当代深度学习与十九世纪几何学的相似之处：架构”动物园”，缺乏统一原理
  • GDL 的野心：用对称性与不变性的一阶原理推导归纳偏置与网络架构
  • 双重目的：
    1. 提供统一框架研究 CNN、RNN、GNN、Transformer 等
    2. 提供将物理先验知识纳入神经架构的构造性程序

1.4 本书边界

  • 核心关注：表示学习架构与数据的对称性
  • 不重点关注：训练 pipeline（自监督、生成模型、强化学习）、优化器（Adam）、正则化（Dropout、BatchNorm）

2. 高维学习（Learning in High Dimensions）

2.1 监督学习的形式化

基本设定

监督学习的最简形式从数据开始。假设我们有 \(N\) 个观测样本组成的训练集：

\[\mathcal{D} = \{(x_i, y_i)\}_{i=1}^{N}\]

这些样本从某个未知的底层数据分布 \(P\) 中独立同分布（i.i.d.） 采样得到。\(P\) 定义在 \(\mathcal{X} \times \mathcal{Y}\) 上，其中：

  • \(\mathcal{X}\) — 数据域（输入空间）
  • \(\mathcal{Y}\) — 标签域（输出空间）

在典型的深度学习场景中，\(\mathcal{X}= \mathbb{R}^d\) 是一个高维欧氏空间，\(d\) 很大（例如一张 256×256 的 RGB 图像对应 \(d = 256 \times 256 \times 3 = 196{,}608\)）。这是整个讨论的出发点：我们必须处理维数极高的输入。

本书后续将把 \(\mathcal{X}\) 从”非结构化向量空间”推广为更结构化的形式——定义在低维几何域 \(\Omega\) 上的信号空间 \(\mathcal{X}(\Omega) = \{x: \Omega \to \mathbb{R}\}\)，例如网格、图或流形。这恰是 GDL 的核心视角转换。

数据生成假设

最简单的假设是标签由某个未知函数 \(f\) 生成：

\[y_i = f(x_i)\]

这意味着我们处于无噪声（noiseless） 的理想化设定中——每个观测的标签完全由输入决定，不存在随机扰动。真实世界中噪声无处不在，但这一简化使我们能首先聚焦于函数逼近的核心问题，而不被随机性分散注意力。

学习问题：参数化函数类

学习问题归结为：从有限样本 \(\mathcal{D}\) 出发，估计未知函数 \(f\)。

估计器来自某个参数化函数类（parametric function class）：

\[\mathcal{F} = \{ f_\theta : \theta \in \Theta \}\]

  • \(\theta \in \Theta\) 是参数，\(\mathcal{F}\) 是参数化的假设空间
  • 神经网络是这类参数化函数类最常见的实现：此时 \(\theta\) 对应网络的权重（weights）
  • 函数类 \(\mathcal{F}\) 的选择本身已经是一种归纳偏置——它限定了哪些函数可以被表示

插值区域（Interpolating Regime）

现代深度学习系统典型地工作在所谓的插值区域：估计得到的函数 \(\tilde{f} \in \mathcal{F}\) 在所有训练点上完美拟合标签：

\[\tilde{f}(x_i) = f(x_i) \quad \text{for all } i = 1, \ldots, N\]

这意味着训练误差为零。经典统计学告诉我们，在低维设定中，完美拟合训练数据通常意味着过拟合（overfitting）——模型记住了训练集的噪声而丧失泛化能力。然而，现代深度网络在高维设定中恰表现出截然相反的行为：尽管完美插值训练数据，它们仍能在测试数据上取得出色的泛化表现。这一反直觉的现象是当前深度学习理论研究的核心谜题之一，也暗示了神经网络本身隐式地编码了某种”好的”归纳偏置。

泛化性能的度量

学习算法的真正性能不由训练集上的表现来衡量，而由其泛化能力——即对从未见过的新样本的预测准确性——来衡量。

给定损失函数 \(L(\cdot, \cdot)\)，定义期望风险（expected risk）：

\[\mathcal{R}(\tilde{f}) := \mathbb{E}_{P} \, L(\tilde{f}(x), f(x))\]

这里 \(\mathbb{E}_P\) 表示对从数据分布 \(P\) 中采样的新数据点求期望。期望风险是对泛化误差的理论刻画——它衡量了学习到的函数 \(\tilde{f}\) 在整个数据分布上的平均表现。

最常用的损失函数之一是平方损失：

\[L(y, y') = \frac{1}{2} |y - y'|^2\]

注：统计学习理论提供了更精细的泛化界，通常基于集中不等式（concentration inequalities） 推导得到。本书主要从几何/对称性角度切入，对统计学习理论部分仅作参考引述。

从形式化到核心问题

上述形式化揭示了一个根本性的张力：

  • 表达能力：\(\mathcal{F}\) 需要足够丰富（dense），以近似任意目标函数（Universal Approximation）
  • 泛化能力：\(\mathcal{F}\) 需要被充分约束，以避免在高维中过拟合

成功的学习方案必须通过 \(\mathcal{F}\) 的构造和正则化（regularisation） 来编码关于 \(f\) 的适当规律性——即归纳偏置（inductive bias）。这正是下一节讨论的核心。

2.2 归纳偏置与函数正则性

从插值到有意义的泛化

上节末尾的张力提出一个关键问题：在一个能表示几乎任意函数的巨大空间 \(\mathcal{F}\) 中，什么机制确保神经网络能从无限多个可行解中选出”正确的”那个？

现代机器学习的实践给出了一部分答案：大规模、高质量的数据集，配合充足的计算资源，使得我们可以设计出容量极高的函数类——它们大到足以插值（完美拟合）整个训练集。神经网络自然地契合这一思路：即使是最简单的架构选择，也产生一个稠密（dense） 的函数类。

\(\mathcal{A}\) 在 \(\mathcal{X}\) 中稠密”的意思是：\(\mathcal{X}\) 里的任意一个点，都能被 \(\mathcal{A}\) 中的某个序列无限逼近。即 \(\mathcal{A}\) 的闭包就是整个 \(\mathcal{X}\)。例如有理数 \(\mathbb{Q}\) 在实数 \(\mathbb{R}\) 中稠密。任意一个实数（比如 \(\pi = 3.14159\ldots\)），你都能用一列有理数 \(3, 3.1, 3.14, 3.141, \ldots\) 去无限逼近它。

放到神经网络的语境里：

\(\mathcal{X}\) = 所有连续函数的空间（无穷维，极其巨大）。\(\mathcal{A}\) = 两层感知机能表示的函数集合。

通用逼近定理说的就是：给定任意一个连续函数（无论多复杂），你都能找到一个两层感知机，让它们之间的误差任意小。即两层感知机这个”小”集合 \(\mathcal{A}\) 在全体连续函数这个”大”空间 \(\mathcal{X}\) 中是稠密的。

打个比方：像素画（马赛克）可以逼近任意图像——只要像素点足够多、足够细。两层感知机就是函数空间里的”像素画”，阶跃函数就是它的”像素块”。

稠密性（Denseness）：集合 \(\mathcal{A} \subset \mathcal{X}\) 在 \(\mathcal{X}\) 中稠密，如果 \(\mathcal{A}\) 的闭包(集合本身 + 集合中所有收敛序列的极限点)等于 \(\mathcal{X}\)： \[\mathcal{A} \cup \left\{ \lim_{i\to\infty} a_i : a_i \in \mathcal{A} \right\} = \mathcal{X}\] 直观理解：\(\mathcal{X}\) 中任意一点都可以被 \(\mathcal{A}\) 中的点任意逼近。

通用逼近定理（Universal Approximation Theorems）

神经网络能”近似任何函数”并非经验猜测，而是有严格的数学保证。通用逼近定理表明，即使是最简单的神经网络也能在函数空间中稠密：

  • 一个两层感知机 \(f(\mathbf{x}) = \mathbf{c}^\top \mathrm{sign}(\mathbf{A}\mathbf{x} + \mathbf{b})\) 在连续函数空间 \(C(\mathbb{R}^d)\) 中稠密
  • 只需一个隐藏层 + sign 非线性激活 + 线性输出层，就能以任意精度逼近任意连续函数
  • 直觉理解（见原文 Figure 1）：隐藏层神经元对应阶跃函数的跃变位置和方向，足够多的阶跃函数组合可以像”乐高积木”一样拼接出任意形状

这些定理在 1990 年代被应用数学家和计算机科学家系统性地证明和推广（Cybenko 1989, Hornik 1991, Barron 1993, Leshno 1993, Maiorov 1999, Pinkus 1999 等）。

关键洞察：通用逼近 ≠ 没有归纳偏置

这一点极易被误解。通用逼近定理说 \(\mathcal{F}\) 能够逼近任意函数——但这并不意味着在实际学习中 \(\mathcal{F}\) 中的所有函数都享有同等地位。

给定一个具有通用逼近能力的假设空间 \(\mathcal{F}\)，我们可以定义一个复杂度度量：

\[c : \mathcal{F} \to \mathbb{R}_+\]

将原始的插值问题重新表述为一个约束优化问题：

\[\tilde{f} \in \arg\min_{g \in \mathcal{F}} c(g) \quad \text{s.t.} \quad g(x_i) = f(x_i) \quad \text{for } i = 1, \ldots, N\]

翻译成自然语言：在所有完美拟合训练数据的函数中，我们选择最简单（复杂度最低）的那个。这是归纳偏置发挥作用的具体方式——不是”能表示什么”（通用逼近已保证这点），而是”偏好什么”（简单者优先）。

经典函数空间中的实现

对于标准的函数空间，复杂度度量可以定义为一个范数（norm） \(\|\cdot\|\)，使 \(\mathcal{F}\) 成为一个 Banach 空间（完备的赋范向量空间）。这带来一个巨大好处：可以直接利用泛函分析中丰富的理论工具。

低维情形中的经典案例是样条插值（spline interpolation）：

  • 三次样条（cubic splines）：复杂度由二阶导数的平方积分定义 \[c(f) = \int_{-\infty}^{+\infty} |f''(x)|^2 \, \mathrm{d}x\] 这捕捉了函数”弯曲程度”的直觉——曲率越小，函数越光滑。相应的插值函数即所谓平滑样条（smoothing spline）。

  • 在低维（\(d=1,2,3\)），这类工具具有精确的数学控制，是信号处理的基石。

神经网络中的复杂度

对于神经网络 \(f_\theta\)，复杂度度量自然地表达为网络权重的函数：

\[c(f_\theta) = c(\theta)\]

几种常用选择：

复杂度度量 公式 直觉
Weight Decay \(c(\theta) = \|\theta\|_2^2\)（权重的 \(L_2\) 范数） 偏好小权重，将函数推向平坦/简单
Path-norm (Neyshabur 2015) 沿网络路径的权重的乘积之和 更精细地刻画网络容量

三种视角的统一

书中从三个互补的视角审视复杂度(这里意思是神经网络的拟合倾向)度量：

1. 泛函分析视角 — 范数 + 约束优化 - 将函数学习视为 Banach 空间中的约束最小化问题 - 复杂度 = 范数，\(\mathcal{F}\) 成为赋范空间

2. 贝叶斯视角 — 先验分布的负对数 - 复杂度度量 \(c(f)\) 等价于函数 \(f\) 的负对数先验 \(-\log p(f)\) - 约束优化 \(\min c(f)\) ≡ 最大后验估计（MAP） - 例如：\(L_2\) 正则化 ≡ Gaussian 先验；\(L_1\) 正则化 ≡ Laplace 先验

从贝叶斯公式出发：

\[p(f \mid \mathcal{D}) \propto p(\mathcal{D} \mid f) \cdot p(f)\]

\(p(f)\) — 先验：在看到任何数据之前，我们认为函数 \(f\) 本身有多”可能”存在

\(p(\mathcal{D} \mid f)\) — 似然：给定函数 \(f\)，观测到数据集 \(\mathcal{D}\) 的概率

\(p(f \mid \mathcal{D})\) — 后验：看到数据后，更新了的信念 我们要找最可能的函数 → 最大化后验（MAP）：

\[\max_f p(f \mid \mathcal{D}) = \max_f p(\mathcal{D} \mid f) \cdot p(f)\]

取负对数，把乘法变加法、最大化变最小化：

\[\min_f \underbrace{-\log p(\mathcal{D} \mid f)}{\text{数据拟合项}} + \underbrace{(-\log p(f))}{\text{复杂度惩罚}}\]

对比约束优化的形式：

\[\min_{g} c(g) \quad \text{s.t.} \quad g(x_i) = f(x_i)\]

约束 \(g(x_i) = f(x_i)\) 对应 \(-\log p(\mathcal{D} \mid g)\) 取到极小值（完美拟合 = 似然最大化） \(c(g)\) 对应 \(-\log p(g)\) 所以 \(c(f) = -\log p(f)\)：复杂度度量就是先验概率的负对数。

具体例子：\(L_2\) 正则化等价于 Gaussian 先验。

Gaussian 分布：\(p(\theta) \propto \exp \left(-\frac{|\theta|^2}{2\sigma^2}\right)\)

取负对数：\(-\log p(\theta) \propto |\theta|^2\) — 这就是 Weight Decay。

它的直觉是：在看数据之前，我就先入为主地相信——权重接近零的函数更”正常”，权重很大的函数很”可疑”。

同理 \(L_1\) 正则化对应 Laplace 先验：\(p(\theta) \propto e^{-\lambda|\theta|}\)，负对数就是 \(\lambda|\theta|\)。直觉是：大部分权重应该精确为零（稀疏性），只有少数起作用的连接。

3. 显式 vs 隐式正则化 - 显式（Explicit）：将 \(c(\theta)\) 直接加入经验损失函数中优化 —— 即结构风险最小化（Structural Risk Minimisation） - 隐式（Implicit）：\(c(\theta)\) 不显式出现在目标函数中，而是作为特定优化算法的副产品自然产生 - 经典事实：梯度下降在欠定最小二乘问题上，会自动收敛到 \(L_2\) 范数最小的插值解 - 这一现象向现代深度网络的推广是当前活跃的研究方向（Blanc 2020, Shamir 2020, Razin 2020, Gunasekar 2017 等）

悬而未决的核心问题

上述讨论最终导向全书要回答的根本问题：

如何定义有效的先验，以捕捉现实世界预测任务的真实规律性和复杂性？

经典函数空间（Sobolev、Lipschitz）中基于范数的先验回答不了这个问题——它们向高维的推广在下一节（2.3 维数灾难）中被证明指数级失败。几何先验（对称性 + 尺度分离）正是本书给出的答案。

2.3 维数灾难（The Curse of Dimensionality）

低维 vs 高维：一个根本性的分水岭

在低维（\(d=1,2,3\)）中进行插值是经典的信号处理任务。我们有极其丰富且精致的数学工具可以对估计误差实现精确控制——样条插值、小波（wavelets）、曲波（curvelets）、脊波（ridgelets）等。这些工具的共同基础是：用越来越复杂的正则性类（Sobolev 空间、Hölder 空间等）去刻画函数的”光滑程度”。

但高维情况完全不同。当我们把同样的正则性类原封不动地搬入高维空间时，它们以一种灾难性的方式失效——这被称为维数灾难（curse of dimensionality）。

Lipschitz 类：一个具体的解剖案例

为了传达这一思想的本质，考虑一个最简单又易于推广到高维的正则性类：1-Lipschitz 函数。

\[f: \mathcal{X} \to \mathbb{R} \quad \text{满足} \quad |f(x) - f(x')| \leq \|x - x'\| \quad \forall x, x' \in \mathcal{X}\]

这个假设极其温和——只要求目标函数是局部光滑的：如果稍微扰动输入 \(x\)（以范数 \(\|x - x'\|\) 衡量），输出 \(f(x)\) 不会剧烈变化。1-Lipschitz 几乎是最弱的光滑性要求：系数的斜率不超过 1。

问题是：如果我们对 \(f\) 的唯一认知就是它是 1-Lipschitz 的，需要多少个观测样本才能保证估计值 \(\tilde{f}\) 在整个空间上接近真实的 \(f\)？

几何直觉：象限构造

书中通过一个精巧的构造来给出答案（Figure 2）。

考虑 \[f(x) = \sum_{j=1}^{2^d} z_j \cdot \phi(x - x_j)\]

  • \(x_j\) 被放置在 \(\mathbb{R}^d\) 的每一个象限（quadrant） 中——总共有 \(2^d\) 个象限
  • \(z_j = \pm 1\) 是每个象限中 \(f\) 的符号
  • \(\phi\) 是一个局部支撑的 Lipschitz “鼓包”函数(只在自己象限内非零的函数，形如一个小山丘)

这一构造的核心是：除非我们在大多数 \(2^d\) 个象限中都观测到了 \(f\) 的值，否则对未观测象限中的符号我们将一无所知——预测误差将恒为常数级（\(\mathcal{O}(1)\)），无论我们用了什么估计方法。

这里的”\(2^d\)“是致命的：象限数随维度 \(d\) 指数增长。这直接意味着所需样本数 \(N\) 必须与 \(2^d\) 同一量级。

可观测宇宙中的质子数（Eddington 数）估计约为 \(10^{80}\)。即使对于中等维度 \(d=100\)，\(2^{100} \approx 10^{30}\) 尚可接受，但现实中的图像数据 \(d\) 通常高达 \(10^5\)–\(10^6\)。

数学形式化：最大差异（Maximum Discrepancy）

上述几何直觉可以通过最大差异的概念严格形式化（von Luxburg & Bousquet 2004）。对于 Lipschitz 类：

\[\kappa(d) = \mathbb{E}_{x, x'} \sup_{f \in \mathrm{Lip}(1)} \left| \frac{1}{N}\sum_{l} f(x_l) - \frac{1}{N}\sum_{l} f(x'_l) \right| \simeq N^{-1/d}\]

\(\kappa(d)\) 衡量两个独立的 \(N\) 样本经验期望之间可能存在的最大差异。\(N^{-1/d}\) 来自一个纯粹的几何事实：在 \(d\) 维空间中，用 \(N\) 个点覆盖一个区域，点与点之间的间距是 \(N^{-1/d}\)。在 \([0,1]\) 线段上均匀放 \(N\) 个点，相邻点间距 = \(1/N = N^{-1}\)。在 \([0,1] \times [0,1]\) 正方形里放 \(N\) 个点(每个维度分到 \(\sqrt{N}\) 个点)，排成 \(\sqrt{N} \times \sqrt{N}\) 的网格。行间距 = 列间距 = \(1/\sqrt{N} = N^{-1/2}\)。

为确保 \(\kappa(d) \simeq \epsilon\)（即泛化误差控制在 \(\epsilon\) 以内），必须有：

\[N = \Theta(\epsilon^{-d})\]

样本量随维度指数增长。相应的样本集合 \(\{x_l\}_l\) 定义了域的一个 \(\epsilon\)-网（\(\epsilon\)-net）：对于 \(d\) 维直径 \(1\) 的欧氏域，\(\epsilon\)-网的大小按 \(\epsilon^{-d}\) 指数增长——这就是维数灾难的几何本质。\(\Theta\) 的含义是 \(N = \Theta(\epsilon^{-d})\) 表示 \(N\) 的增长率和 \(\epsilon^{-d}\) 同阶——既不会更省，也不会更差。它们是成比例的：你要求精度提高 10 倍（\(\epsilon \to \epsilon/10\)），样本量就要涨 \(10^d\) 倍。

直观验证：

\(d\) \(N=100\) 时的间距 \(N^{-1/d}\)
1 0.01（1% 精度，很好）
3 0.215（21% 精度，勉强）
10 0.631（63% 精度，很差）
100 0.955（几乎无信息）

同样的样本量，维度越高，样本点被”稀释”得越稀疏，你对函数能知道的信息就越少。想在 \(d=100\) 时达到 \(d=1\) 的间距 0.01，需要 \(N = (1/0.01)^{100} = 10^{200}\) 个样本。

Sobolev 类：光滑性假设也救不了

将 Lipschitz 类替换为更强的全局光滑性假设（如 Sobolev 类 \(\mathcal{H}^s\)）后情况有所改善，但未解决根本问题。

Sobolev 类 \(\mathcal{H}^s(\Omega_d)\)：\(f \in L^2(\Omega_d)\) 且其 \(s\) 阶广义导数是平方可积的（在 Fourier 域中 \(\int |\omega|^{2s+1} |\hat{f}(\omega)|^2 d\omega < \infty\)）。\(s\) 越大，函数越光滑。

经典结果（Tsybakov 2008）给出 Sobolev 类的 minimax 最优收敛率为：\[\epsilon^{-d/s}\]

这意味着光滑性假设 \(s\) 只有在 \(s \propto d\) （\(s\) 与维度成正比）时才能真正改善统计图景——即需要函数极其光滑。在实践中，要求一个自然函数具有与输入维度成比例的高阶光滑性是不现实的。

总结：经典的正则性类（无论是温和的 Lipschitz 还是强光滑的 Sobolev）向高维的推广都以失败告终。它们”成长得太快”——函数类在维度增加时膨胀得过于剧烈，以至于学习变得在统计上不可行。

神经网络的出路——及其代价

全连接神经网络提供了一种不同的可能性。通过在权重上施加复杂度度量 \(c(\theta)\)（等价于 2.2 节中的稀疏正则化），神经网络有能力打破维数灾难（Bach 2017）。

但这有一个关键的前提条件：目标函数 \(f\) 必须可以被近似为：

\[f(\mathbf{x}) \approx g(\mathbf{A}\mathbf{x}), \quad \mathbf{A} \in \mathbb{R}^{k \times d}, \; k \ll d\]

即 \(f\) 本质上只依赖于输入向量的少量低维投影的组合。换言之，高维输入 \(\mathbf{x}\) 中的大部分方向对函数输出来说是无关紧要的。

为什么这一假设在现实中不成立

书中用 MNIST 图像的低通滤波实验给出了一个简洁的反驳（Figure 3）：

对输入图像施加低通滤波器（相当于投影到低维子空间），虽然保留了图像的大部分语义信息（数字类别仍可辨认），但大量细节信息被丢失。

在真实的计算机视觉、语音分析、物理或化学应用中，我们关心的函数倾向于展现复杂的长程相关性——无法用低维投影来表达。一张自然图像中的物体间的空间关系、遮挡、光照变化，或一个分子中各原子间的非局部相互作用，都远非 \(g(\mathbf{A}\mathbf{x})\) 所能捕获。

结论：必须寻找新的正则性来源

经典函数空间正则性 → 维数灾难使之失效。神经网络稀疏正则化 → 低维投影假设不现实。

因此必须定义另一种正则性来源——不是来自抽象的”光滑度”，而是来自物理域本身的空间结构和 \(f\) 的几何先验。这正是第 3 节（Geometric Priors）的出发点。

3. 几何先验（Geometric Priors）

3.1 信号空间的数学定义

从向量空间到信号空间

第 2 节的讨论停留在”输入是非结构化向量 \(\mathbf{x} \in \mathbb{R}^d\)“的框架中。Geometric Deep Learning 的核心范式转换在于重新理解输入的本质：

输入不是一堆任意的数字，而是定义在某个几何域 \(\Omega\) 上的函数（信号）。

这是全书的视角转换。例如，一幅 \(n \times n\) 的 RGB 图像并不是”一个 \(3n^2\) 维的向量”——虽然它可以被展开成那样——而是一个从 2D 网格到颜色空间的映射：

\[x: \underbrace{\mathbb{Z}_n \times \mathbb{Z}_n}_{\text{域 } \Omega} \rightarrow \underbrace{\mathbb{R}^3}_{\text{通道 } \mathcal{C}}\]

每个像素位置 \(u = (i,j)\) 对应一个 RGB 三元组 \(x(u) = (R, G, B)\)。

为什么不直接处理向量？

因为域 \(\Omega\) 上携带着几何结构——网格的平移对称性、图的排列对称性、流形的曲率——这些结构在将信号强行展开为向量时全部丢失。GDL 的整个计划就是利用这些几何结构来约束学习。为此，必须首先将信号空间精确地数学化。

信号空间的形式定义

给定域 \(\Omega\)（一个集合，可能附带额外几何结构）和向量空间 \(\mathcal{C}\)（其维度称为通道数），定义：

\[\mathcal{X}(\Omega, \mathcal{C}) = \{ x : \Omega \rightarrow \mathcal{C} \}\]

  • 域 \(\Omega\)：信号的”定义域”——网格、图、流形、群等。\(\Omega\) 本身不必是向量空间（如：图上的节点不能直接做加法），我们可以直接在任意集合上定义信号
  • 通道空间 \(\mathcal{C}\)：信号在每个点上的取值空间，通常是 \(\mathbb{R}^s\)（\(s\) 个通道）
  • \(\mathcal{X}(\Omega, \mathcal{C})\) 本身是一个函数空间

当 \(\Omega\) 带有额外结构（如光滑流形），可以进一步限制信号类（如要求光滑）。之后我们将尽可能缩写为 \(\mathcal{X}(\Omega)\)，省略 \(\mathcal{C}\)。

域 \(\Omega\)

书中的 \(\Omega\) 就是信号的定义域——信号 \(x\) 的输入来自哪里。它可以是非常一般的集合：

例子 \(\Omega\) 是否有向量空间结构？
图像 \(\mathbb{Z}_n \times \mathbb{Z}_n\)（像素网格） 否。网格上的两个像素位置不能相加——\((i,j) + (i',j')\) 没有意义
社交网络 图 \(G = (\mathcal{V}, \mathcal{E})\) 否。节点是离散的标签，节点之间无加法
3D 形状 流形 \(\mathcal{M}\)（如球面 \(S^2\)） 否。球面上两点相加不落在球面上
一般情况 任意集合 \(\Omega\) 不需要任何代数结构

域可以携带额外的几何结构——距离（度量）、拓扑（连续性）、微分结构（光滑性）——这些结构被对称性群所保护。但它们不必须能”做加法”。

向量空间 \(V\)

向量空间 \(V\) 是一个集合，配备两种运算：

  1. 加法：\(\forall u, v \in V\)，有 \(u + v \in V\)
  2. 标量乘法：\(\forall \alpha \in \mathbb{R}, v \in V\)，有 \(\alpha v \in V\)

且满足八条公理：加法结合律、加法交换律、零元、加法逆元、标量乘法的结合律、标量乘法的单位元、标量对向量的分配律、向量对标量的分配律。

直观上：向量空间是”可以做线性组合的地方”。\(\mathbb{R}^d\) 是最常见的例子。

\(\Omega\) 不是向量空间，但 \(\mathcal{X}(\Omega, \mathcal{C})\) 是

这是 3.1 节最核心的洞察。用一个表格对比：

\(\Omega\)（域） \(\mathcal{X}(\Omega, \mathcal{C})\)（信号空间）
是什么 信号的”地址”集合 信号的”取值”全体
元素长什么样 像素坐标 \((i,j)\) RGB 函数 \(x: (i,j) \mapsto (R,G,B)\)
能加吗？ 不一定（图节点不能加） 总能（逐点加）
有零元吗？ 不一定 有（逐点为零的函数 \(x(u) = \mathbf{0}\)）
是向量空间？ 不一定 一定是

一旦 \(\mathcal{X}(\Omega, \mathcal{C})\) 是向量空间（并且有内积后成为 Hilbert 空间），我们就可以在其中做：

  • 线性运算：卷积、Fourier 变换、Laplacian 的特征分解
  • 正交分解：信号可以投影到正交基上
  • 范数：度量信号的”大小”和”距离”

而这一切都不要求 \(\Omega\) 本身是向量空间。这就是为什么线性代数/泛函分析的工具能被用到任意形状的域（图、流形）上——它们不是在域上操作，而是在定义于域上的信号空间上操作。

向量空间结构

虽然 \(\Omega\) 上的点不能相加，但信号可以。在 \(\mathcal{X}(\Omega, \mathcal{C})\) 上定义逐点运算：

\[(\alpha x + \beta y)(u) = \alpha x(u) + \beta y(u) \quad \forall u \in \Omega\]

其中 \(\alpha, \beta \in \mathbb{R}\) 是实标量。即：对每个位置 \(u\)，单独做该位置上的加法和标量乘法。

这使 \(\mathcal{X}(\Omega, \mathcal{C})\) 成为一个向量空间。关键洞察是：

\[\Omega \text{ 不是向量空间} \quad\not\Rightarrow\quad \mathcal{X}(\Omega, \mathcal{C}) \text{ 不是向量空间}\]

物理域可以是一般的（图、流形、群），但信号空间总是线性的。

从向量空间到 Hilbert 空间

向量空间给了我们加法和标量乘法。要让几何和正交性有意义，还需要内积：

  • 在通道空间 \(\mathcal{C}\) 上，假设有内积 \(\langle \cdot, \cdot \rangle_\mathcal{C}\)（例如 \(\mathbb{R}^s\) 上的标准点积）
  • 在域 \(\Omega\) 上，给定测度 \(\mu\)（连续域上用 Lebesgue 测度，离散域上用计数测度——此时积分退化为求和）
  • 在 \(\mathcal{X}(\Omega, \mathcal{C})\) 上定义内积：

\[\langle x, y \rangle = \int_{\Omega} \langle x(u), y(u) \rangle_{\mathcal{C}} \; d\mu(u)\]

当 \(\Omega\) 离散时（如 \(n \times n\) 网格），上式退化为：

\[\langle x, y \rangle = \sum_{u \in \Omega} \langle x(u), y(u) \rangle_{\mathcal{C}}\]

配备了此内积后，\(\mathcal{X}(\Omega, \mathcal{C})\) 成为一个 Hilbert 空间（完备的内积空间）。这是后续所有理论的基础——Laplacian 的特征分解、Fourier 变换在一般域上的推广、卷积的几何定义——全都需要 Hilbert 空间结构。

两大几何先验

有了信号空间的定义，可以从域的几何结构中提取两种普遍的归纳偏置：

1. 对称性（Symmetry）：域 \(\Omega\) 通常具有对称性——平移（网格）、排列（图/集合）、旋转（球面）等。这些对称性构成群，通过群作用传递给信号空间，进而约束能定义在信号上的函数 \(f\)——要求它们是等变或不变的。

2. 尺度分离（Scale Separation）：将信号转移到域的粗粒化版本上（对 \(\Omega\) 做下采样），能保留信号的重要特征。在 CNN 中体现为池化（pooling）操作。

一个贯穿全书的例子

取 \(\Omega = \mathbb{Z}_n \times \mathbb{Z}_n\)（\(n \times n\) 的 2D 网格），信号 \(x: \Omega \to \mathbb{R}^3\) 是一幅 RGB 图像。

  • 对称性 → 平移不变/等变 → CNN 中的卷积核权重共享：同一个滤波器滑过所有像素位置
  • 尺度分离 → 池化：在粗粒化的网格上汇总局部信息

将这两个原理推广到任意域（图、流形、群等）并展示它们如何从基本原理出发自然地导出相应的神经架构——这就是几何深度学习的核心任务。

本节为信号空间”搭好了舞台”。下一节（3.2）开始引入”演员”——对称性群及其在信号空间上的作用。

3.2 对称性、表示与不变性

什么是对称性？

非正式地，一个对象或系统的对称性（symmetry） 是一种变换，它使该对象或系统的某些性质保持不变（invariant）。这些变换可以是：

类型 例子 应用场景
连续（Continuous） 平移、旋转 图像分类 → 平移不变；分子性质预测 → 旋转不变
离散（Discrete） 排列（permutation）、时间反演 粒子系统 → 排列不变（粒子无规范顺序）；动力系统 → 时间反演对称

对称性在机器学习任务中无处不在，只是我们常常习以为常。当我们期望一只猫无论出现在图像的左上角还是右下角都应被分类为”猫”时，我们已经在使用平移对称性作为归纳偏置。

对称群（Symmetry Groups）

对称性不是孤立存在的——它们可以被组合。如果 \(\mathfrak{g}\) 和 \(\mathfrak{h}\) 都是对称变换，那么它们的复合（先 \(\mathfrak{h}\) 后 \(\mathfrak{g}\)）也是对称变换：若每次变换都不改变对象，复合变换自然也不改变。对称变换总是可逆的，且逆变换也是对称的。

这些性质使所有对称性的集合构成一个代数结构——群（Group）：

群是一个集合 \(\mathfrak{G}\) 配上二元运算 \(\circ : \mathfrak{G} \times \mathfrak{G} \to \mathfrak{G}\)（称为复合，简写为并列 \(\mathfrak{g} \circ \mathfrak{h} = \mathfrak{g}\mathfrak{h}\)，从右向左读：先 \(\mathfrak{h}\) 后 \(\mathfrak{g}\)），满足：

公理 含义
结合律 \((\mathfrak{g}\mathfrak{h})\mathfrak{k} = \mathfrak{g}(\mathfrak{h}\mathfrak{k})\) 三个变换复合时，括号位置不重要
单位元 \(\exists \mathfrak{e}: \mathfrak{e}\mathfrak{g} = \mathfrak{g}\mathfrak{e} = \mathfrak{g}\) “什么都不做”是对称性
逆元 \(\forall \mathfrak{g}, \exists \mathfrak{g}^{-1}: \mathfrak{g}\mathfrak{g}^{-1} = \mathfrak{g}^{-1}\mathfrak{g} = \mathfrak{e}\) 每个对称变换可以”撤销”
封闭性 \(\forall \mathfrak{g}, \mathfrak{h} \in \mathfrak{G}: \mathfrak{g}\mathfrak{h} \in \mathfrak{G}\) 两个对称复合后仍是对称

注意：交换性不是公理。一般的群 \(\mathfrak{g}\mathfrak{h} \neq \mathfrak{h}\mathfrak{g}\)。满足交换性的群称为交换群或 Abel 群（以挪威数学家 Niels Henrik Abel 命名）。群的复合顺序很重要。

一些常见群

1.\(E(d)\) — Euclidean 群（全等距群）

\(E(d)\) 是 \(d\) 维欧几里得空间的所有等距变换的集合——即保持任意两点距离不变的所有变换。

包含三种操作：

  • 平移：把整个空间沿着某个方向挪
  • 旋转：绕着某个轴转
  • 反射：沿着某个平面翻转（镜像）

\(d\) 是维度：\(E(2)\) = 平面的等距群，\(E(3)\) = 3D 空间的等距群。

2.\(SE(d)\) — Special Euclidean 群（保定向等距群）

\(SE(d)\) 是 \(E(d)\) 的子群，去掉了反射。

只包含：平移 + 旋转（及两者的组合）。\(SE(d)\) 保持距离 且 保持定向——右手坐标系永远是右手坐标系。

类比：你可以把一张纸在桌上滑动和旋转（\(SE(2)\)），但你不能把它翻过来（翻面 = 反射 = 属于 \(E(2)\) 但不属于 \(SE(2)\)）。

3.\(O(d)\) — Orthogonal群（正交群，含反射的旋转群）

\(O(d)\) 只包含 \(d\) 维空间中保持原点不动的等距：旋转 + 反射，但不含平移。

\(O(d)\) 里的矩阵满足：\(\mathbf{R}^\top \mathbf{R} = \mathbf{I}\)（正交矩阵）。

4.\(SO(d)\) — Special Orthogonal群（特殊正交群，纯旋转群）

\(O(d)\) 中去掉反射 = 只保留旋转。行列式为 +1 的正交矩阵。

\[SO(2) = \text{平面上的纯旋转} \quad SO(3) = \text{3D 空间的纯旋转}\]

\(SO(3)\) 是球面 CNN 的核心对称群——后续章节会大量出现。

生成元与 Lie 群

群可以非常庞大甚至无限，但常常可以由少数几个元素生成：

  • 生成元（Generator）：子集 \(S \subseteq \mathfrak{G}\)，使得每个群元素都可以写成 \(S\) 中元素及其逆的有限复合

    • 例：等边三角形的对称群 \(D_3\) → 仅需一个 \(60^\circ\) 旋转和一个反射即可生成全部 6 个对称（原文 Figure 4）

      6 个元素可以全部由组合得到。取生成元 \(R\)（旋转）和 \(F_1\)（过顶点 1 的反射）：

      • \(R\) → 120° 旋转
      • \(R^2\) → 240° 旋转（= \(R\) 做两次）
      • \(R^3 = \mathfrak{e}\)
      • \(F_1\) → 固定 1 的反射
      • \(F_1 \circ R\) → 先旋转再反射 = \(F_3\)（固定 3 的反射）
      • \(F_1 \circ R^2\) → \(F_2\)（固定 2 的反射）

      2 个生成元就生成整个 6 元素群。注意 \(D_3\) 不是 Abel 群：\(R \circ F_1 \neq F_1 \circ R\)（先转后翻 ≠ 先翻后转）——这也是为什么书中强调群的复合顺序很重要。

  • Lie 群：具有微分流形结构的连续对称群

    • 1D 平移群 → 由无穷小平移生成
    • \(SO(3)\)（3D 旋转）→ 一个 3 维紧流形，每个 3D 旋转由旋转轴（单位向量，2 个自由度——球面上的一个方向）和旋转角度（1 个自由度）共同决定 = 共 3 个自由度

    对比：

    离散群 \(D_3\) Lie 群 \(SO(3)\)
    元素个数 6 个（离散） 无穷多（连续）
    几何结构 没有，就是有限集合 3 维光滑流形
    局部坐标 无 可用 3 个连续参数描述
    例子 三角形的 6 种对称 3D 空间所有旋转

抽象群 vs 具体群

群是抽象定义的——只规定元素如何复合，不规定元素”是什么”。因此截然不同的对象可能具有同一个对称群：

\(D_3 \cong \Sigma_3\)：等边三角形的旋转/反射对称群 = 三个元素的排列群

这是因为三角形的每个对称变换恰好对应其三个顶点的一个排列：翻转载三个标签，旋转是循环移位。群的结构相同，尽管物理实现完全不同。

群作用（Group Action）

仅有抽象群还不够。GDL 关心的是群如何作用于数据。

第一步：群作用于域 \(\Omega\)

群 \(\mathfrak{G}\) 在域 \(\Omega\) 上的（左）群作用是一个映射：

\[(\mathfrak{g}, u) \mapsto \mathfrak{g}.u\]

将群元素 \(\mathfrak{g} \in \mathfrak{G}\) 和点 \(u \in \Omega\) 关联到 \(\Omega\) 中的另一点，且与群运算兼容：

\[\mathfrak{g}.(\mathfrak{h}.u) = (\mathfrak{g}\mathfrak{h}).u\]

例：Euclidean 群 \(E(2)\) 作用在平面 \(\mathbb{R}^2\) 上——平移、旋转、反射将平面上的点映射到另一点。

例：假设 \(\Omega\) 是一条直线（1D 空间），\(\mathfrak{G}\) 是平移群。\(g = +3\) 表示”向右平移 3 个单位”。

群作用 \(g.u\) 就是把点 \(u\) 按规则 \(g\) 挪到新位置：

\[g.u = u + 3\]

\(u = 5\)，则 \(g.u = 5 + 3 = 8\)。这是对空间上的点的操作。

第二步：群作用于信号空间 \(\mathcal{X}(\Omega)\)

域 \(\Omega\) 上的群作用自动诱导出信号空间 \(\mathcal{X}(\Omega)\) 上的群作用：

\[\boxed{(\mathfrak{g}.x)(u) = x(\mathfrak{g}^{-1}u)}\]

这是全书最重要的公式之一。逐字解释：

  • 输入：一个群元素 \(\mathfrak{g}\) 和一个信号 \(x\)
  • 输出：一个新的信号 \(\mathfrak{g}.x\)
  • 这个新信号在点 \(u\) 处的值 = 原信号 \(x\) 在被 \(\mathfrak{g}^{-1}\) 拉回的点处的值

为什么是 \(\mathfrak{g}^{-1}\) 而非 \(\mathfrak{g}\)？ 验证兼容性：

\[(\mathfrak{g}.(\mathfrak{h}.x))(u) = (\mathfrak{h}.x)(\mathfrak{g}^{-1}u) = x(\mathfrak{h}^{-1}\mathfrak{g}^{-1}u) = x((\mathfrak{g}\mathfrak{h})^{-1}u) = ((\mathfrak{g}\mathfrak{h}).x)(u)\]

若不加逆，则顺序会颠倒为 \(x(\mathfrak{h}^{-1}\mathfrak{g}^{-1}u)\) → \(x((\mathfrak{h}\mathfrak{g})^{-1}u)\)，与群复合顺序冲突。逆元的出现保证了这是一个合法的（左）群作用。

\(g^{-1}\) 的出现不是数学的奇技淫巧，而是物理直觉的自然结果：要计算信号被 g 变换后在 u 处的值，你需要回溯到 g 变换之前的那个位置——即用 g 的逆拉回。

同一个群 \(E(2)\) 既作用在平面上（挪动点），也作用在图像空间上（挪动整个图像）。更重要的是，它还会作用在神经网络学到的表示空间上——这种”穿透性”使得几何约束可以贯穿整个网络。

例：信号 \(x\) 是定义在 \(\Omega\) 上的函数，比如 \(x(u) = u^2\)（一条抛物线）。

现在问题来了：把信号向右平移 3，新的信号 \(x'\) 应该是什么？

直觉：原来在位置 \(u=5\) 的值 \(x(5) = 25\)，平移后应该出现在位置 \(u=8\)。换言之，新信号在 \(u=8\) 的值 = 旧信号在 \(u=5\) 的值。

\[x'(8) = x(5) = x(8 - 3) = x(g^{-1} \cdot 8)\]

因为 \(g = +3\)，\(g^{-1} = -3\)，\(g^{-1}.u = u - 3\)。

所以新信号的定义：

\[x'(u) = x(u - 3) = x(g^{-1}u)\]

用群作用的符号写成：

\[(g.x)(u) = x(g^{-1}u)\]

群表示（Group Representation）

最重要的群作用是线性群作用，即群表示。信号空间上的作用 \((\mathfrak{g}.x)(u) = x(\mathfrak{g}^{-1}u)\) 恰好是线性的：

\[\mathfrak{g}.(\alpha x + \beta x') = \alpha(\mathfrak{g}.x) + \beta(\mathfrak{g}.x')\]

此处 \(\alpha,\beta\) 是系数，不是变换。

我们可以等价地将线性作用描述为从群到矩阵的映射（为变换写一个矩阵表示）：

\(n\) 维实表示 \(\rho: \mathfrak{G} \to \mathbb{R}^{n \times n}\) 为每个 \(\mathfrak{g} \in \mathfrak{G}\) 分配一个可逆矩阵 \(\rho(\mathfrak{g})\)，满足： \[\rho(\mathfrak{g}\mathfrak{h}) = \rho(\mathfrak{g})\rho(\mathfrak{h})\] 这称为同态（homomorphism） 性质：群复合对应矩阵乘法。先做 \(h\) 再做 \(g\)（群复合 \(gh\)），和”先用矩阵 \(\rho(h)\) 作用再用矩阵 \(\rho(g)\) 作用（矩阵乘法 \(\rho(g)\rho(h)\)）“完全等价。一旦有了矩阵，线性代数知识就都能用上了。

几个要点：

  • 表示维度 \(n\) 与群维度无关：\(n\) 是表示空间（如特征空间）的维度，在深度学习中通常对应特征通道数或像素数。例如 2D 平移群作用在 \(n\) 个像素的图像空间上

  • 正则表示：在信号空间上 \(\rho(\mathfrak{g})x(u) = x(\mathfrak{g}^{-1}u)\)，这是 GDL 中最常见的表示形式

  • 酉表示（Unitary）/正交表示（Orthogonal）：若对所有 \(\mathfrak{g}\)，\(\rho(\mathfrak{g})\) 是酉矩阵 / 正交矩阵。这类表示在理论和计算上都特别友好——它们在后续的 Fourier 分析和谱方法中将起关键作用

  • 当 \(\Omega\) 无穷时（连续域），\(\rho(\mathfrak{g})\) 是无限维线性算子而非有限维矩阵；实际应用中总是离散化为有限网格

三个空间：GDL 的核心图景

原文 Figure 5 展示了 GDL 的三个关键空间及其关系：

空间 含义 群如何作用
\(\Omega\) 物理域（网格、图、流形） \(\mathfrak{g}.u\) — 挪动域上的点
\(\mathcal{X}(\Omega)\) 信号空间（函数空间） \(\rho(\mathfrak{g})x\) — 通过表示作用
\(\mathcal{F}(\mathcal{X}(\Omega))\) 假设类（我们学习的函数） 被对称性约束——要求 \(f\) 是等变或不变的

这是一个”传导链”：域的对称性 → 信号空间的表示 → 假设类的结构约束。正是这一链条将几何转化为归纳偏置。

不变性（Invariance）

域 \(\Omega\) 的对称性将结构施加于作用于信号上的函数 \(f\)，强制缩小可能的插值函数空间 \(\mathcal{F}(\mathcal{X}(\Omega))\)——这就是对称性作为归纳偏置的精确数学机制。

函数 \(f: \mathcal{X}(\Omega) \to \mathcal{Y}\) 是 \(\mathfrak{G}\)-不变的，如果： \[f(\rho(\mathfrak{g})x) = f(x) \quad \forall \mathfrak{g} \in \mathfrak{G}, \; \forall x \in \mathcal{X}(\Omega)\] 输出不受群作用的影响。

经典例子：平移不变的图像分类

  • 猫在图像左上角还是右下角 → 分类结果应该相同
  • 输出是单个类别标签（\(\mathcal{Y}\) 是一组概率值）
  • 多层感知机（MLP）没有这个性质——这是 1970 年代 MLP 在模式识别中失败的核心原因之一：MLP 把移位后的同一张图像当作完全不同的输入向量
  • CNN 的出现很大程度是为了满足平移不变性：局部权重共享的卷积核 + 全局池化 = 有效的平移不变架构
符号 含义 具体例子
\(x\) 输入信号 一张猫的图片（\(256 \times 256\) 像素网格上的 RGB 值）
\(\mathfrak{g}\) 群中的一个变换 “向右平移 10 像素”
\(\rho(\mathfrak{g})\) 该变换的矩阵表示 把图像整体平移的线性算子
\(\rho(\mathfrak{g})x\) 变换后的信号 猫移到右边 10 像素后的图片
\(f(\cdot)\) 我们想学习的函数 一个图像分类器
\(f(x)\) 原图的输出 输入原图 → 输出 “猫”
\(f(\rho(\mathfrak{g})x)\) 变换后图片的输出 输入右移 10 像素的图 → 输出 ???

不变性要求两者相等：\(f(\rho(\mathfrak{g})x) = f(x)\)

等变性（Equivariance）

然而仔细检查 CNN 的卷积层会发现：它们并非平移不变，而是平移等变——输入的平移导致输出特征图同幅度的平移。

函数 \(f: \mathcal{X}(\Omega) \to \mathcal{X}(\Omega)\) 是 \(\mathfrak{G}\)-等变的，如果： \[f(\rho(\mathfrak{g})x) = \rho(\mathfrak{g}) f(x) \quad \forall \mathfrak{g} \in \mathfrak{G}, \; \forall x \in \mathcal{X}(\Omega)\] 输入上的群作用在输出上被忠实地再现。

更一般的形式：当输入和输出具有不同的域或不同的表示时， \[f(\rho(\mathfrak{g})x) = \rho'(\mathfrak{g}) f(x)\]

其中 \(\rho, \rho'\) 是同一个群 \(\mathfrak{G}\) 的不同表示。

经典例子：平移等变的图像分割

  • 输入：RGB 图像 → 域 = 网格，\(\mathcal{C} = \mathbb{R}^3\)
  • 输出：像素级分割掩码 → 域 = 同一网格，\(\mathcal{C}' = \mathbb{R}^{(\text{类别数})}\)
  • 输入左移 5 像素 → 分割掩码也左移 5 像素（等变），而非不变

不变性 vs 等变性：并非二选一

整个 CNN 的分类流水线就是等变和不变的分工合作：

\[\text{卷积层（等变）} \to \cdots \to \text{卷积层（等变）} \to \text{全局池化（不变）}\]

等变层保持空间信息，逐层构建越来越抽象的特征；最后的全局池化将等变特征”折叠”为不变输出。这是 GDL 蓝图（3.6 节）的核心模式，对 CNN、GNN 等都适用。

为什么仅有线性不变量不够？

先看有限群的情形，假设 \(\mathfrak{G}\) 只有有限个元素（比如 \(D_3\) 有 6 个元素）。群上的”平均值”就是普通的算术平均：\[A(x) = \frac{1}{|\mathfrak{G}|} \sum_{\mathfrak{g} \in \mathfrak{G}} \mathfrak{g}.x\]

若\(f\) 既是线性的，又是\(\mathfrak{G}\)-不变的。

因为 \(f\) 是不变的：对每个集合中的群元素 \(\mathfrak{g}\)，\(f(x) = f(\mathfrak{g}.x)\)。也就是说：

\[f(x) = f(\mathfrak{g}_1.x) = f(\mathfrak{g}_2.x) = \cdots = f(\mathfrak{g}_6.x)\]

全部相等。那么取平均当然还是同一个值：

\[f(x) = \frac{1}{6} \left[ f(\mathfrak{g}_1.x) + f(\mathfrak{g}_2.x) + \cdots + f(\mathfrak{g}_6.x) \right]\]

因为 \(f\) 是线性的：\(f(a + b) = f(a) + f(b)\) 且 \(f(\alpha a) = \alpha f(a)\)。所以可以把 \(f\) 从求和号里提出来：

\[f(x) = f\left( \frac{1}{6} \left[ \mathfrak{g}_1.x + \mathfrak{g}_2.x + \cdots + \mathfrak{g}_6.x \right] \right)\]

括号里的东西正好就是群平均 \(A(x)\)所以：

\[f(x) = f(A(x))\]

得出结论：\(f\) 只能”看到”群平均这个单一信息。 所有精细结构都被洗掉了。

举个例子：图像 + 平移群

\(x =\) 一张猫的图片。\(\mathfrak{G} =\) 所有可能的平移（把图像上下左右挪）。群平均：

\[A(x) = \text{对所有平移位置取平均}\]

结果是什么？图像中每个像素的 RGB 值被平均成一个全局常数——整张图像变成一种单一的平均颜色。

这说明线性 + 不变 = 太强了。两者的组合把所有信息都”平均掉了”。

但线性 + 等变是好的。等变不需要平均——它保留空间结构，只是跟着变换一起挪位置：

\[f(\rho(\mathfrak{g})x) = \rho(\mathfrak{g}) f(x)\]

然后逐层加非线性 \(\sigma\)：\(\sigma \circ f\) 仍然是等变的。非线性给了表达力（不洗掉信息），等变给了几何结构（保留域上的空间关系）。最后一层才做一次不变池化（全局平均或最大池化）——在最高语义层把空间信息折叠掉，获得变换不变的最终输出。

再看连续群的情形，连续群（如平移群 \(\mathbb{R}\)、旋转群 \(SO(3)\)）有无穷多个元素，求和变成积分：

\[\frac{1}{|\mathfrak{G}|} \sum_{\mathfrak{g}} \quad\to\quad \frac{1}{\mu(\mathfrak{G})} \int_{\mathfrak{G}} d\mu(\mathfrak{g})\]

一个深刻的观察：如果 \(f\) 同时满足线性和 \(\mathfrak{G}\)-不变，则：

\[f(x) = \frac{1}{\mu(\mathfrak{G})} \int_{\mathfrak{G}} f(\mathfrak{g}.x) \, d\mu(\mathfrak{g}) = f\!\left(\frac{1}{\mu(\mathfrak{G})} \int_{\mathfrak{G}} (\mathfrak{g}.x) \, d\mu(\mathfrak{g})\right)\]

（\(\mu(\mathfrak{g})\) 是群上的 Haar 测度——群上的”均匀分布”，核心性质是平移不变：\(\mu(\mathfrak{h} \cdot S) = \mu(S)\)——群中任意子集 \(S\) 的”体积”不随群元素 \(\mathfrak{h}\) 的挪动而改变。就像 Lebesgue 测度在 \(\mathbb{R}\) 上是平移不变的同行——你测量一个区间的长度，不因区间挪了位置而改变；积分遍历整个群。）

这意味着 \(f\) 仅依赖于 \(x\) 的群平均 \(A(x) = \frac{1}{\mu(\mathfrak{G})} \int_{\mathfrak{G}} (\mathfrak{g}.x) \, d\mu(\mathfrak{g})\)。

具体后果： - 图像 + 平移群：\(A(x) =\) 整个图像所有像素的 RGB 平均值。一个分类器若只看平均颜色，几乎什么也分不出来 - 图 + 排列群：\(A(x) =\) 所有节点特征的平均值。丢失了全部图结构信息

结论：线性不变量的表达力太弱。但线性等变量通过与非线性的组合，可以构建出丰富且稳定的特征——这是深度几何架构设计的核心动机。

3.3 同构与自同构（Isomorphisms and Automorphisms）

什么是”对称性”取决于保留了什么结构

前文的讨论隐含了一个问题：什么变换算作”对称”？答案取决于我们选择保留域的哪些结构。这引出一个重要概念：域 \(\Omega\) 上可以叠加多个层次的结构，每个层次对应一个不同的对称群。

同构（Isomorphism）：来自希腊语”相等的形状”。不同对象间可逆且保结构的映射。对象到自身的同构 = 自同构（Automorphism）= 对称性。

结构层次：从粗到细

在最低层次上，\(\Omega\) 仅仅是一个集合，只有 基数（cardinality）概念（有限集 = 元素个数；无限集 = 可数无穷 vs 连续统）。保结构的自映射 = 双射（bijection）（可逆映射，一一对应、无遗漏）。双射是集合层面”保结构”的映射，因为集合的唯一”结构”就是它的元素及元素个数。双射不丢失、不复制元素——基数被完美保留。

集合的所有双射构成集合自同构群 \(\mathrm{Aut}(\Omega)\)。

验证它确实是群：(1)双射的复合仍是双射（封闭性），(2)复合本质上有结合性，(3)群内存在恒等映射 \(\tau(u) = u\) 是单位元，(4)每个双射按定义存在逆（满足 \(\tau \circ \tau^{-1} = \tau^{-1} \circ \tau = \mathrm{id}\)）。

即使是信息最贫乏的情形（只知道 \(\Omega\) 是集合），“所有对称性”也已经自然地形成一个群。当往 \(\Omega\) 上添加更多结构（距离、光滑性），只是在这个大群里选取满足额外条件的子群。整条”结构层次”链就是逐步缩小子群的过程。

\[\mathrm{Diff}(\Omega) \subset \mathrm{Homeo}(\Omega) \subset \mathrm{Aut}_{set}(\Omega)\]

而最顶层的集合自同构群 \(\mathrm{Aut}(\Omega)\) = 所有排列的集合 = \(\Sigma_n\)——这恰好是 GNN 和 Deep Sets 中的排列对称群。这个群不是人为选的，而是从集合的最简定义中自然涌现的。

根据应用需要，可以逐层增加结构——每加一层，相应的保结构映射群就缩小：

结构层次 保结构的映射 群 直观理解
集合（仅有基数） 双射（Bijection） \(\mathrm{Aut}(\Omega)\) 只要”一一对应”即可
拓扑（连续性） 同胚（Homeomorphism） 连续且逆连续；邻域映射到邻域
微分（光滑性） 微分同胚（Diffeomorphism） \(\mathrm{Diff}(\Omega)\) 可微且逆可微；流形结构
度量（距离） 等距（Isometry） \(E(d)\) 保距离；刚体运动
定向 保定向映射 \(SE(d)\) 不含反射/翻转

每一层都对映射施加了更严格的条件： - 双射：仅要求一一对应——“所有点还在，且没有重复” - 同胚：连续且逆连续——“把咖啡杯连续变形为甜甜圈”在拓扑学中是合法的（两者同胚） - 微分同胚：光滑且逆光滑(可以取任意阶导数)——不允许尖角或断裂——“橡胶膜的拉伸但不能撕破” - 等距：保距离——“只允许刚体运动（旋转+平移）”，远严格于微分同胚（不允许拉伸、压缩、任何形变），出现了距离的概念（给出一个函数 \(d(u,v)\) 为任意两点赋予一个非负实数），满足下面三条性质 - 同一性：\(d(u,v) = 0\) 当且仅当 \(u = v\)（不重合的两个点距离 > 0） - 对称性：\(d(u,v) = d(v,u)\)（A 到 B 的距离 = B 到 A） - 三角不等式：\(d(u,v) \leq d(u,w) + d(w,v)\)（绕道必定不近于直走） - 保定向：连续群 \(SO(d)\) vs 含反射的全等距群 \(E(d)\)——“右手系不能变成左手系” - \(E(2)\) 包含反射（翻转），反射改变定向 - \(SE(2)\) 从 \(E(2)\) 中去掉反射，只保留旋转和平移——保定向的等距 - \(SE(2) \subset E(2) \subset \mathrm{Diff}(2)\)

为什么选择正确的层次至关重要

书中用两个医学影像的对比示例说明：

任务 正确的结构层次 原因
组织病理切片分割 含反射的等距 \(E(2)\) 样本可在显微镜下被翻转——翻转后仍是同一样本
交通标志分类 仅保定向的 \(SE(2)\) 反射会改变标志含义（左转箭头翻转后 = 右转）

这意味着没有普适的”正确”对称群——群的选择是问题特定的，取决于你对数据生成过程的理解。

子群：用数学语言编码”更多结构”

添加结构 = 选择原群的子群：

\(\mathfrak{H} \subseteq \mathfrak{G}\) 是 \(\mathfrak{G}\) 的子群，如果 \((\mathfrak{H}, \circ)\) 本身构成一个群（封闭、含有单位元、对每个元素有逆元）。

子群关系链： \[\mathrm{SE}(2) \subset \mathrm{E}(2) \subset \mathrm{Diff}(2)\]

保定向刚体运动 ⊂ 全等距 ⊂ 所有光滑形变。群越小 → 不变量越多 → 约束越强 → 样本效率越高（但也可能过度约束）。

这正好呼应了前言中 Erlangen 纲领的逻辑：在 Klein 的构造中，射影几何、仿射几何、欧氏几何分别对应逐步缩小的群——群越小，保留的不变量越多，几何”越刚性”。

自同构 vs 同构：为什么需要区分？

本书使用精确的术语：

  • 自同构（Automorphism） \(\tau: \Omega \to \Omega\)：对象到自身的保结构映射 = 对称性
  • 同构（Isomorphism） \(\eta: \Omega \to \Omega'\)：两个不同对象间的保结构映射

这两个概念常被混用，但区分它们对 GDL 的清晰性至关重要。

集合的例子：\(\Omega = \{0, 1, 2\}\)

自同构：\(\tau(u) = u + 1 \bmod 3\)（循环移位）——把 \(\{0,1,2\}\) 映射回自身，保基数。

同构：\(\Omega' = \{a, b, c\}\)，定义 \(\eta(0) = a, \eta(1) = b, \eta(2) = c\)——这是一个集合同构，\(\Omega\) 和 \(\Omega'\) 在集合论意义上”完全相同”（仅名称不同）。

图的例子（第 2 文档将详细展开）：设 \(\mathcal{G} = (\mathcal{V}, \mathcal{E})\) 为图，\(\mathcal{V}\) = 节点，\(\mathcal{E}\) = 边。

  • 图同构 \(\eta: \mathcal{V} \to \mathcal{V}'\)：节点间的双射，使得 \((u,v) \in \mathcal{E}\) 当且仅当 \((\eta(u), \eta(v)) \in \mathcal{E}'\)。两个同构的图结构完全相同，仅节点编号不同。
  • 图自同构 \(\tau: \mathcal{V} \to \mathcal{V}\)：节点到自身的排列，保边连接。非平凡自同构（\(\tau \neq \mathrm{id}\)）的存在意味着图具有对称性。

Folkman 图是图自同构的经典范例——一种有着 3840 个自同构的图，可以用许多对称的方式画出来。

为什么这对 GDL 很重要？

对于 GDL，同构和自同构都至关重要：

  • 对称性（自同构） → 通过等变/不变层编码进网络架构（3.2 节的内容）
  • 同构 → 要求网络对结构相同但表示不同的对象给出相同的答案——两个仅仅是节点编号不同的图应当得到相同的分类结果

但现实世界充满噪声。精确的同构/自同构假设在以下情形下崩溃： - 图被轻微编辑（丢失或新增了边） - 图像被微小形变（不完全是一个平移，但”几乎”是） - 3D 形状被非刚性拉伸

这自然引向下一节的主题：形变稳定性——从精确对称性到”近似对称性”的过渡。

3.4 形变稳定性（Deformation Stability）

精确对称性的两个失败模式

第 3.2–3.3 节的形式化捕捉的是一个理想化世界：我们精确知道哪些变换算作对称性，并要求函数对这些变换精确等变或不变。在计算机视觉中，这相当于假设”平面平移是精确对称性”——物体平移后，语义完全相同。

现实世界中的噪声使这一模型在两个方向上失效：

失败模式 1：全局对称性无法捕获局部变化

考虑一段视频：画面中有多辆车，每辆车沿着自己的方向、以自己的速度行驶。下一帧中：

  • 没有一个单一的全局平移能解释从一帧到下一帧的变换
  • 但语义信息（“画面中有车在行驶”）大致保持不变

类似地，一个可形变 3D 物体（如一个被压扁又弹回的橡胶球）在被相机拍摄时，几乎不可能用有限维群来精确描述”保物体身份”的变换族。

结论：现实中我们关心的变换远比精确的全局对称群大得多——全局精确不变/等变被局部的、近似的不变/等变所取代。

失败模式 2：“小形变”不构成群

直观上，一个微小的形变（\(\tau \approx\) 恒等）不应改变 \(f(x)\) 的输出——“只差一点点”的输入应该给出”只差一点点”的输出。

问题在于：“小形变”的集合不满足群的封闭性公理。两个 \(\epsilon\)-等距（与精确等距距离 \(\leq \epsilon\)）的复合最多是 \(2\epsilon\)-等距——“小”不能保证在复合下封闭。所以我们不能把”小形变”当作一个对称群来处理。

另一方面，用整个微分同胚群 \(\mathrm{Diff}(\Omega)\) 作为对称群也不合适——大的形变会实质性地改变输入的语义内容（把猫的图像拉伸成不可辨认的图案）。

信号形变稳定性

出路：定义一个形变代价 \(c(\tau)\) 来量化一个变换 \(\tau\) 与给定对称子群 \(\mathfrak{G}\) 的距离。关键性质：

\[c(\tau) = 0 \quad \text{当} \quad \tau \in \mathfrak{G}\]

即代价精确为零当且仅当 \(\tau\) 是群内的一个精确对称变换。这允许我们在 \(\mathfrak{G}\) 附近”软化”约束：

函数 \(f\) 是几何稳定的（geometrically stable），如果存在常数 \(C\)（与信号 \(x\) 无关），使得对所有 \(x \in \mathcal{X}(\Omega)\)： \[\| f(\rho(\tau) x) - f(x)\| \leq C \cdot c(\tau) \cdot \|x\|\]

  • 左端 \(\| f(\rho(\tau) x) - f(x)\|\)：将输入信号 \(x\) 按 \(\tau\) 形变后喂给 \(f\)，与直接喂原信号给 \(f\)，两者输出的差异
  • 右端 \(C \cdot c(\tau) \cdot \|x\|\)：这个差异被形变代价 \(c(\tau)\) 乘上信号的”大小” \(\|x\|\) 所线性控制
  • \(\tau\) 越接近 \(\mathfrak{G}\)（\(c(\tau)\) 越小）→ 输出差异越小
  • \(\tau \in \mathfrak{G}\) → \(c(\tau) = 0\) → 输出差异 = 0 → 回到精确不变性

这条不等式把”\(\mathfrak{G}\)-不变”从二值条件（是/否）推广为连续条件（偏离量由 \(c(\tau)\) 定量控制）。

一个具体例子：图像的 Dirichlet 能量

对于定义在连续欧几里得平面上的图像，一个广泛使用的形变代价是Dirichlet 能量：

\[c^2(\tau) = \int_\Omega \|\nabla \tau(u)\|^2 \, du\]

直观理解： - \(\nabla \tau(u)\) 是形变场在点 \(u\) 处的”空间变化率” - 若 \(\tau\) 是精确平移（常数位移向量场），则 \(\nabla \tau \equiv 0\)，\(c(\tau) = 0\) - 若 \(\tau\) 有局部拉伸或剪切（\(\nabla \tau \neq 0\)），Dirichlet 能量积累”弹性偏离”

Dirichlet 能量本质上衡量的是：\(\tau\) 与平移群的偏离有多远。它实际上是一个范数——这使 \(c\) 享有范数带来的所有理论便利（如三角不等式、标量乘法）。

核心图景：Aut(\(\Omega\)) 中的”灰环”

原文 Figure 6 提供了关键的几何直觉：所有双射构成整个自同构群 \(\mathrm{Aut}(\Omega)\)。对称群 \(\mathfrak{G}\)（如平移群）是其中的一个圆（子群）。几何稳定性将 \(\mathfrak{G}\)-不变/等变的概念延拓到 \(\mathfrak{G}\) 周围的”灰环”——即 \(c(\tau)\) 很小的那些 \(\tau\)，它们虽然不属于 \(\mathfrak{G}\)，但”几乎”是群元素。

域形变稳定性

此前讨论假设域 \(\Omega\) 固定，仅信号受到形变。但很多应用中域本身也在变化。

可以这样看：

  • \(\Omega\)（域）是画布——它规定了”哪里可以画”。网格是一张坐标纸，图是节点连线的拓扑，流形是一个弯曲的面
  • \(x\)（信号）是画布上的颜料——在每个可画的位置上填了具体值。图像是 RGB 值，节点特征是向量
  • 信号形变：画布不变，颜料被抹了一下。同一张 \(256 \times 256\) 的画布，猫图被拉伸——像素的 RGB 值被重新分配到附近的坐标上。域相同，信号被扭曲
  • 域形变：画布本身变了，颜料随之重新附着。比如社交网络今天的关注图（\(\Omega_1\)）和明天的关注图（\(\Omega_2\)）画布结构不同——有人取关，边消失了。信号（用户发帖内容）被搬到了新的画布上
应用 域形变例子
社交网络 不同时间点的关注图——边被增加或删除
3D 形状分析 同一个物体被非刚体形变（弯曲、拉伸）
分子建模 不同构象的分子对应略有不同的图结构

看一个具体示例：两个图 \(\Omega\) 和 \(\tilde{\Omega}\)

右边的图少了一条边（\(b\) 没有连到 \(c\)），它们不是同构的。

现在有一组节点特征（信号）定义在两个图上：

  • \(x\)：\(\Omega\) 上定义，\(x(1) = 0.8, x(2) = 0.3, x(3) = 0.5\)
  • \(\tilde{x}\)：\(\tilde{\Omega}\) 上同样的值通过某个”对应关系”搬运过去

希望分类器 \(f\) 对两个图给出相似的答案（比如这两个图都代表”大约是三人的小群组”），尽管它们不完全同构。可以定义一个域间距离 \[d_\mathcal{D}(\Omega, \tilde{\Omega}) = \inf_{\eta \in \mathfrak{G}} |d - \tilde{d} \circ (\eta \times \eta)|\]

  • \(d\)：\(\Omega\) 上的距离/邻接结构。对于图，\(d(u,v)\) 可以是”\(u\) 和 \(v\) 之间是否有边”（0/1 的邻接矩阵）
  • \(\tilde{d}\)：\(\tilde{\Omega}\) 上的距离/邻接结构
  • \(\eta: \Omega \to \tilde{\Omega}\)：一个对齐映射——“把 \(\Omega\) 的节点与 \(\tilde{\Omega}\) 的节点配对”。比如 \(\eta(1)=a, \eta(2)=b, \eta(3)=c\)
  • \(\tilde{d} \circ (\eta \times \eta)\)：先对齐，再算 \(\tilde{\Omega}\) 的距离。即 \(\tilde{d}(\eta(u), \eta(v))\)——“对齐后的 \(\tilde{\Omega}\) 结构”
  • \(|d - \tilde{d} \circ (\eta \times \eta)|\)：在对齐 \(\eta\) 下，两个域的结构差异有多大
  • \(\inf_{\eta \in \mathfrak{G}}\)：遍历所有可能的对齐方式，取差异最小的那个。\(\mathfrak{G}\) 是同构群——例如图的排列群 \(\Sigma_n\)，或流形的等距群。\(\inf\) 拿到的是”在最佳对齐下，两个域还剩多少结构差异”。如果最佳对齐时差异为零 → 两域同构（图同构/流形等距）。

域的度量：记 \(\mathcal{D}\) 为所有可能域的空间（如所有图的空间，或所有黎曼流形的空间）。为 \(\Omega, \tilde{\Omega} \in \mathcal{D}\) 定义域间距离 \(d_\mathcal{D}(\Omega, \tilde{\Omega})\)，使得：

  • 图：\(d_\mathcal{D} = 0\) 当两图同构 → 图编辑距离（graph edit distance）——通过一系列编辑操作（删边、加边、增删节点）使两个图同构的最小代价
  • 流形：\(d_\mathcal{D} = 0\) 当两流形等距 → Gromov-Hausdorff 距离——两个度量空间之间最小可能的度量扭曲

通用构造方式：通过结构对齐映射 \(\eta: \Omega \to \tilde{\Omega}\)（同构，如双射或等距）对齐两个域，比较它们的距离/邻接结构：

\[d_\mathcal{D}(\Omega, \tilde{\Omega}) = \inf_{\eta \in \mathfrak{G}} \|d - \tilde{d} \circ (\eta \times \eta)\|\]

其中 \(\mathfrak{G}\) 是同构群（如排列群或等距群），范数定义在乘积空间 \(\Omega \times \Omega\) 上。这个公式的思想是：通过所有可能的对齐方式（\(\eta \in \mathfrak{G}\)），找到使两个域的内部结构（距离矩阵或邻接矩阵）差异最小的那个对齐——差异的最小值就是域间距离。

域形变稳定性条件：给定原域 \(\Omega\) 上的信号 \(x \in \mathcal{X}(\Omega)\)，先通过 \(\eta^{-1}\) 将其”搬运”到形变后的域 \(\tilde{\Omega}\) 上得到 \(\tilde{x} = x \circ \eta^{-1} \in \mathcal{X}(\tilde{\Omega})\)。函数 \(f: \mathcal{X}(\mathcal{D}) \to \mathcal{Y}\) 对域形变稳定，如果：

\[\| f(x, \Omega) - f(\tilde{x}, \tilde{\Omega}) \| \leq C \cdot \|x\| \cdot d_\mathcal{D}(\Omega, \tilde{\Omega})\] 对所有的 \(\Omega, \tilde{\Omega} \in \mathcal{D}\) 和 \(x \in \mathcal{X}(\Omega)\) 成立。

这一定义将在后续的流形和网格章节（第 3 文档）中扮演关键角色——等距形变在 3D 形状分析中至关重要。

两个域在结构上很接近（\(d_\mathcal{D}\) 很小），那么定义在这两个域上的相似信号，经过 \(f\) 处理后，输出也应该很接近。\(f\) 的输出随域的变化是”可控的”——不会因为域被轻微编辑而崩溃。

与信号形变稳定性的类比（两者的精神一致：把”精确不变”软化为”误差随偏离量线性增长”）：

变化的是什么 控制因素
信号形变稳定性 信号 \(x\) 被 \(\tau\) 扭曲 \(c(\tau)\) — \(\tau\) 离群有多远
域形变稳定性 域 \(\Omega\) 本身被编辑 \(d_\mathcal{D}(\Omega, \tilde{\Omega})\) — 两个域有多”近”

可以证明：域形变稳定性是信号形变稳定性的自然推广——后者可以重新表述为体积形式（volume form）的形变（Gama 2019）。

二次指派问题（QAP） 是图对齐的具体实现：对于同样大小为 \(n\) 的两个图，求 \(\min_{\mathbf{P} \in \Sigma_n} \mathrm{trace}(\mathbf{A} \mathbf{P} \tilde{\mathbf{A}} \mathbf{P}^\top)\)，其中 \(\mathbf{A}, \tilde{\mathbf{A}}\) 为邻接矩阵，\(\Sigma_n\) 为排列矩阵群。

两个图 \(G\) 和 \(\tilde{G}\)，都有 \(n\) 个节点。邻接矩阵 \(\mathbf{A}\) 和 \(\tilde{\mathbf{A}}\) 描述了各自的边结构。

QAP 问题：如何把 \(G\) 的节点与 \(\tilde{G}\) 的节点配对（排列），使两个邻接矩阵”对得最齐”？

\[\min_{\mathbf{P} \in \Sigma_n} \mathrm{trace}(\mathbf{A} \mathbf{P} \tilde{\mathbf{A}} \mathbf{P}^\top)\]

  • \(\mathbf{P}\) 是一个 \(n \times n\) 排列矩阵（每行每列恰有一个 1，其余为 0）。\(\mathbf{P}[i, j] = 1\) 表示”把 \(G\) 的节点 \(i\) 配给 \(\tilde{G}\) 的节点 \(j\)”
  • \(\mathbf{P} \tilde{\mathbf{A}} \mathbf{P}^\top\) = 把 \(\tilde{G}\) 的邻接矩阵按排列 \(\mathbf{P}\) 重新编号（翻转行和列），使节点顺序与 \(G\) 对齐
  • \(\mathbf{A} (\mathbf{P} \tilde{\mathbf{A}} \mathbf{P}^\top)\) = 对齐后的两个邻接矩阵逐元相乘
  • \(\mathrm{trace}\) = 取矩阵对角线之和 = 所有对应位置的乘积之和

对于每一对 \((i, j)\) 节点：\(\mathbf{A}[i, j] \times\)（对齐后 \(\tilde{\mathbf{A}}\) 在 \((i, j)\) 的值）

  • 若两个图中 \((i, j)\) 都有边：\(1 \times 1 = 1\) → 贡献到一致计数
  • 若一个有边一个无边：\(1 \times 0 = 0\) → 不贡献
  • 若都无边：\(0 \times 0 = 0\) → 不贡献

所以 \(\mathrm{trace}\) = 对齐后两个图共享边的总数。

一个具体例子

\(\mathbf{A}\)（\(G\)）：\((1,2), (1,3), (2,1), (3,1)\) 位置为 1，其余为 0

\(\tilde{\mathbf{A}}\)（\(\tilde{G}\)）：\((a,b), (a,c), (b,a), (b,d), (c,a), (c,d), (d,b), (d,c)\) 位置为 1

排列 \(\mathbf{P}\)：\(\mathbf{P}\)：\(1 \to a, 2 \to b, 3 \to c, 4 \to d\)

QAP 的目标就是转动 \(\mathbf{P}\) 的所有排列，找到让”两边都有边的节点对”最多的那个排列。

从 \(G\) 变成 \(\tilde{G}\) 的最少编辑操作（等价于图编辑距离，使两图同构所需的最少编辑操作数，包括增删边、节点）：加两条边（\(2-4\) 和 \(3-4\)）= 编辑距离 = 2。排列 \(\mathbf{P}\) 将节点 4 映射到 \(d\)，但 4 是孤立的——所以 \(b-d\) 和 \(c-d\) 这两个连接在 \(G\) 中完全缺失。

\(d_\mathcal{D}(G, \tilde{G}) = 2\) — 需要 2 个编辑操作才能使二者同构。这个非零距离正是域形变稳定性公式中控制 \(|f(x,\Omega) - f(\tilde{x},\tilde{\Omega})|\) 上界的那个因子。

\(\Sigma_n\) 有 \(n!\) 种可能的排列。想要找到最优的那个，必须逐一比较——没有捷径。（QAP 是 NP-hard，显式求解 QAP 完全不可能）

GNN 的替代策略：不求解 QAP，而是让网络”感觉不到”排列

回到 GDL 的基本思路。前文讨论过，对于图数据，对称群是排列群 \(\Sigma_n\)。排列不变意味着：

\[f(\rho(\mathbf{P})x) = f(x)\]

改变节点的编号顺序，网络的输出不变。（\(f\) 不在乎节点的标签是 \((0,1,2)\) 还是 \((2,0,1)\)——它只看到同样的结构、同样的特征值集合）

这等价于对于任意两个同构图 \(G\) 和 \(\tilde{G}\)（它们仅节点编号不同，由某个 \(\mathbf{P}\) 关联），\(f\) 自动给出完全相同的输出。你不需要去”找”这个 \(\mathbf{P}\)——网络的架构已经保证了任何 \(\mathbf{P}\) 都不会影响结果。

QAP 方式：给你两张照片，你逐像素比对，找出它们是不是同一个人。计算量随像素数指数爆炸。

GNN 方式：你训练了一个人脸识别网络，不管照片怎么裁剪、缩放、平移（这些 = 排列的类比），网络输出同一个身份标签。网络从来不去显式地对齐任何两张照片——架构本身已经内化了”平移/缩放等不影响身份”这一先验。

QAP 给不出确定性答案——两个图不是完全同构，不存在完美的排列对齐。但 GNN 通过消息传递 + 聚合，逐层构建局部结构的层次化表示，使得：

  • 结构相似的两个图（仅差几条边）→ 网络内部表示相近 → 输出相近
  • 结构迥异的两个图 → 表示差异大 → 输出差异大

这正是域形变稳定性在起作用——GNN 隐式地实现了”\(d_\mathcal{D}\) 小则输出差异小”的保证，而不需要显式地计算 \(d_\mathcal{D}\)。

从形变稳定性到尺度分离

形变稳定性大幅强化了全局对称性先验，但它本身仍不足够克服维数灾难。非正式地讲，随着域的大小增长，满足形变稳定性条件的函数仍然”太多”——需要额外的结构来进一步削减函数空间。

下一节引入的关键工具是尺度分离——利用物理任务的多尺度结构来组织这些稳定表示。

3.5 尺度分离（Scale Separation）

形变稳定性还不够

形变稳定性大幅强化了全局对称性先验，但它单独不足以克服维数灾难。非正式地讲，随着域 \(\Omega\) 的大小增长，仍存在”太多”的函数满足形变稳定性条件——假设空间仍然过大。突破这一瓶颈的关键洞察是：利用物理任务固有的多尺度结构。

Fourier 变换：频率与全局不变量

在讨论多尺度表示之前，需要引入调和分析的基石——Fourier 变换。它是按频率而非尺度组织信号的。

经典 1D Fourier 变换：

\[\hat{x}(\xi) = \int_{-\infty}^{\infty} x(u) e^{-i\xi u} \, du\]

将函数 \(x(u) \in L^2(\Omega)\)（\(\Omega = \mathbb{R}\)）表示为正交振荡基函数 \(\varphi_\xi(u) = e^{i\xi u}\) 的线性组合，按振荡速率 \(\xi\)（频率） 索引。这种频率组织揭示了信号的重要信息——光滑性、局部化程度等。

Fourier 基有深刻的几何根源——可以解释为域的自然振动模式（本征模态），与域的 Laplacian 算子紧密关联。这一几何视角使得 Fourier 分析可以推广到非欧域：图、群、流形——通过该域上内蕴定义的微分算子（Laplacian 的特征分解）。

本节所述的 Fourier 变换不限于一维欧氏域——后续将在任意几何域上再次出现（第 3 文档）。

卷积定理：Fourier 变换在信号处理中的核心地位源自它给卷积提供了一种对偶形式：

\[(x \star \theta)(u) = \int_{-\infty}^{\infty} x(v)\theta(u - v) \, dv\]

卷积算子在 Fourier 基下被对角化：

\[\widehat{(x \star \theta)}(\xi) = \hat{x}(\xi) \cdot \hat{\theta}(\xi)\]

即在 Fourier 域中，卷积变为逐频率的点乘。这一事实是 CNN 的数学基础——卷积在频域中有简明的表征。

实践中机器学习常混用卷积和互相关（cross-correlation） \((x \star \theta)(u) = \int x(v)\theta(u+v)dv\)；由于滤波器通常是可学习的，两者仅差一个符号，区分不必严格。

Fourier 基的全局性：Fourier 基函数 \(\varphi_\xi(u) = e^{i\xi u}\) 在整个域上有全局支撑——每个基函数在所有 \(u\) 上非零。结果：信号中一个局部的不连续点在 Fourier 域中产生跨越所有频率的能量。

Fourier 的形变不稳定性

Fourier 表示对精确平移极为友好，但这对近似形变不是事实。

精确平移情形：平移算子 \(S_v\)（\(S_v x(u) = x(u - v)\)）在 Fourier 域中仅改变相位：

\[(\widehat{S_v x})(\xi) = e^{-i\xi v} \hat{x}(\xi)\]

因此 Fourier 模 \(f(x) = |\hat{x}|\) 是精确的平移不变量（取模去掉了相位）： \[f(S_v x) = |e^{-i\xi v}\hat{x}(\xi)| = |\hat{x}(\xi)| = f(x)\]

近似平移情形：考虑 \(\tau(u) = u - \tilde{\tau}(u)\) （\(\tilde{\tau}(u)\) 不是常数，它随位置 \(u\) 变化），其中 \(\|\nabla\tilde{\tau}\|_\infty \leq \epsilon\)——这是”几乎是一个平移”的形变。此时：

\[\frac{\|f(\rho(\tau) x) - f(x)\|}{\|x\|} = \mathcal{O}(1)\]

无论 \(\epsilon\) 多小！换言之，Fourier 模对任意小的形变都是不稳定的——即使 \(\tau\) 无限接近平移，Fourier 模仍可能产生常数级的偏差。

直观理解：高频 Fourier 分量对微小的几何扭曲极度敏感——局部形变 \(\tau\) 即使在小邻域内改变了空间结构，高频相位就会出现巨大偏移，导致 Fourier 模的崩塌。这种不稳定性在一般域和非刚体变换中同样存在——第 3 文档将在 3D 形状分析中再次遇到 Fourier 扩展版本的类似问题。

小波与多尺度表示

Fourier 频率表示 → 全局但不稳定。

小波表示 → 局部且稳定。

核心思路：将信号按尺度（而非频率）分解为在空间和频率上同时局部化的基本元素。

连续小波变换：由一个母小波 \(\psi\) 通过平移和伸缩生成小波原子：

\[(W_\psi x)(u, \xi) = \xi^{-1/2} \int_{-\infty}^{\infty} \psi\!\left(\frac{v - u}{\xi}\right) x(v) \, dv\]

  • \(u\) = 小波原子的空间位置（平移参数）
  • \(\xi\) = 小波原子的尺度/伸缩（\(\xi\) 大 = 宽小波 = 粗尺度；\(\xi\) 小 = 窄小波 = 精细尺度）
  • 实际计算中通常做二进采样（dyadic sampling）：\(\xi = 2^{-j}\)，\(u = 2^{-j} k\)，其中 \(j\) 称为尺度参数

Fourier vs 小波：

Fourier 小波
基函数支撑 全局（整个域） 局部（有限窗）
组织方式 按频率 \(\xi\) 按尺度 \(j\) + 位置 \(u\)
对局部不连续点的响应 能量扩散到所有频率 能量集中在不连续点邻域
表示 正交基 过完备（冗余）表示
形变稳定性 \(\mathcal{O}(1)\) — 不稳定 \(\mathcal{O}(\epsilon)\) — 近似等变

小波表示的冗余性（过完备）不是缺陷而是特征——它提供了数值稳定性，使信号在形变下保持可追踪。

小波的形变稳定性

回到上节的近似平移 \(\tau(u) = u - \tilde{\tau}(u)\)，\(\|\nabla\tilde{\tau}\|_\infty \leq \epsilon\)。对于小波分解，可以证明（Mallat 2012）：

\[\frac{\|\rho(\tau)(W_\psi x) - W_\psi(\rho(\tau) x)\|}{\|x\|} = \mathcal{O}(\epsilon)\]

即小波变换对形变是近似等变的：形变后的小波系数约等于小波系数的形变——误差与 \(\epsilon\) 成比例，可控。

这揭示了从 Fourier 到小波的范式转换：

\[\text{Fourier: } \mathcal{O}(1) \text{ 不稳定} \quad\to\quad \text{小波: } \mathcal{O}(\epsilon) \text{ 近似等变}\]

关键洞察：用局部化滤波器按尺度（而非全局频率）分解信号信息 → 将一个全局不稳定表示转化为一系列局部稳定的特征族。

但重要的一点是：这些不同尺度的测量不是不变的——它们需要逐步向低频/粗尺度聚合。这自然暗示了神经网络需要的深度组合结构——这正是 GDL 蓝图的核心。

尺度分离先验：从物理到机器学习

基于小波稳定性，可以将域 \(\Omega\) 多尺度粗粒化（抽象出信息）为一个层次结构：

\[\Omega = \Omega_1 \supseteq \Omega_2 \supseteq \cdots \supseteq \Omega_J\]

粗粒化将邻近的点 \(u, u' \in \Omega\) 合并到一起——这一操作只需域上定义了合适的度量（距离概念）。网格、图、流形上都允许这样的粗粒化。

以图像分类为例，一张 \(256 \times 256\) 的图像是否需要我们在每个像素层面逐点分析？不需要。

一个 CNN 做什么：

  • 底层（精细尺度）：检测边缘、纹理斑点——局部 \(3 \times 3\) 感受野
  • 中层：将这些基本纹理组合成”眼睛”、“轮子”——感受野扩大到几十像素
  • 高层：“眼睛+鼻子+嘴 = 脸”——感受野覆盖整张图像

这个从局部到全局的过程取决于尺度层次——通过逐层粗粒化（池化）将域逐步缩小：

\[256 \times 256 \to 128 \times 128 \to 64 \times 64 \to \cdots\]

在网格上粗粒化：将 \(2 \times 2\) 的方块合并为一个粗像素（平均池化或最大池化）。在图上粗粒化：将相邻节点合并为一个”超级节点”。

记 \(\mathcal{X}_j(\Omega_j, \mathcal{C}_j) = \{x_j: \Omega_j \to \mathcal{C}_j\}\) 为定义在粗粒化域上的信号。非正式地说，函数 \(f: \mathcal{X}(\Omega) \to \mathcal{Y}\) 在尺度 \(j\) 上局部稳定，如果存在分解：

\[f \approx f_j \circ P_j\]

  • \(f\)：目标函数（如”这张图里有猫吗”）
  • \(P_j\)：粗粒化算子，把精细域 \(\Omega\) 上的信号压缩到粗域 \(\Omega_j\) 上
  • \(f_j\)：定义在粗域上的分类器——它接收的信号维度远低于原信号
  • \(f \approx f_j \circ P_j\)：先局部压缩再全局分类的结果 ≈ 直接在精细域上分类的结果

\(P_j: \mathcal{X}(\Omega) \to \mathcal{X}_j(\Omega_j)\) 是非线性粗粒化算子，\(f_j: \mathcal{X}_j(\Omega_j) \to \mathcal{Y}\) 定义在粗尺度上。

含义：目标函数 \(f\) 可能依赖整个域上特征间的复杂长程交互。但在局部稳定函数中，这些交互可以被跨尺度分离——先在精细尺度上处理局部交互，再逐步向粗尺度传播。粗尺度上的 \(f_j\) 处理的是已经过局部聚合的信息——空间范围更大，但信息量更紧凑。

物理/数学中的先例：

领域 尺度分离的体现
统计物理 重整化群（Renormalisation Group） — 从微观自由度出发逐层粗粒化得到宏观描述
数值分析 快速多极子方法（FMM） — 将距离相近的源聚合成单个源以加速 \(n\) 体计算
机器学习 局部池化（Local Pooling） — CNN 中的 max/average pooling；GNN 中的图粗粒化

这三种实例分享了同一个数学直觉：先局部聚合，再全局传播。尺度分离先验精确地刻画了 CNN 和 GNN 效率的数学本质，也是未来工作将从计算调和分析统一发展应用于各个几何域的理论工具。

从三个先验到蓝图

至此，三类几何先验已全部展开：

先验 核心思想 神经网络实现
对称性（3.2–3.3） 群作用 → 不变/等变函数 等变层 + 全局池化
形变稳定性（3.4） 精确不变 → 近似不变的软化 稳定性不等式自动满足（设计得当的架构）
尺度分离（3.5） 多尺度粗粒化 → 先局部后全局 局部池化 + 深层组合

三者联合 → 几何深度学习蓝图（3.6 节）。

3.6 GDL 蓝图（The Blueprint）

四个构建块（Building Blocks）

  1. 线性 \(\mathfrak{G}\)-等变层 \(B: \mathcal{X}(\Omega, \mathcal{C}) \to \mathcal{X}(\Omega', \mathcal{C}')\)
    • \(B(\mathfrak{g}.x) = \mathfrak{g}.B(x)\)
  2. 逐点非线性 \(\sigma: \mathcal{C} \to \mathcal{C}'\)
    • \((\boldsymbol{\sigma}(x))(u) = \sigma(x(u))\)
    • 保等变性：若 \(B\) 等变，则 \(\boldsymbol{\sigma} \circ B\) 亦然
  3. 局部池化（粗粒化） \(P: \mathcal{X}(\Omega, \mathcal{C}) \to \mathcal{X}(\Omega', \mathcal{C})\)，\(\Omega' \subseteq \Omega\)
  4. \(\mathfrak{G}\)-不变层（全局池化） \(A: \mathcal{X}(\Omega, \mathcal{C}) \to \mathcal{Y}\)
    • \(A(\mathfrak{g}.x) = A(x)\)

最终形式

\[f = A \circ \boldsymbol{\sigma}_J \circ B_J \circ P_{J-1} \circ \cdots \circ P_1 \circ \boldsymbol{\sigma}_1 \circ B_1\]

关键性质

  • 等变层的组合仍是等变的（群表示需匹配）
  • 局部化（增加感受野半径 \(r\) 的邻域）+ 深层组合 → 扩大感受野
  • 单层局部等变无法捕获长程交互，深度组合可以 → 保持稳定性同时获得表达能力
  • 池化层实现尺度分离先验
  • 最终全局池化将等变表示折叠为不变输出

两种设置

设置 域 \(\Omega\) 稳定性需求 例子
固定域 不变 信号形变稳定性 图像分类
可变域 与信号一起变化 域形变稳定性 图分类

架构 ↔︎ 域 ↔︎ 对称群对照表

架构 域 \(\Omega\) 对称群 \(\mathfrak{G}\)

Spherical CNN 球面 / \(SO(3)\) 旋转 \(SO(3)\)
Intrinsic / Mesh CNN 流形 等距 \(\mathrm{Iso}(\Omega)\) / 规范对称 \(SO(2)\)

核心概念回顾

  1. 维数灾难 → 通用正则性类（Lipschitz, Sobolev）指数级失败
  2. 对称性 → 群作用 + 群表示 → 不变性 / 等变性
  3. 形变稳定性 → 从精确群不变到”近似不变”的软化
  4. 尺度分离 → Fourier 全局但不稳定 ↔︎ Wavelet 局部且稳定
  5. GDL 蓝图 = 等变层 + 非线性 + 局部池化 + 全局池化的组合

三个几何先验（对称性、形变稳定性、尺度分离）→ 一个统一的架构构造程序。
